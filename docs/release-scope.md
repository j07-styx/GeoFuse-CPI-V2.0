# Release scope

## Included

- V2.0 architecture and methodology documentation.
- Aggregate-only benchmark ledger and native-geometry audit.
- Frozen checkpoint/prediction archive identity hashes.
- Dataset/source provenance and comparator references.
- Reproduction levels, validation gates and explicit claim boundaries.
- A public metadata consistency checker.

## Excluded

- Model checkpoint binaries and training weights.
- Raw datasets, numerical assay labels and protected test outcomes.
- Per-example prediction arrays and source structures.
- Local virtual environments, credentials and user-specific paths.
- V363, V499, V48, production v6 or other experimental branch results.
